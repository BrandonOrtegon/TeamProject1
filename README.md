# Collin College Library Database Part 1

Collin College Library Database allows users to enter 5 books into the database that includes: title and genre. Then, the program displays the titles that the user entered and lets the user search through the database through names of the books or genres.

Link to live demo

https://onecompiler.com/java/44rgygeth
